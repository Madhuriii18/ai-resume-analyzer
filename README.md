# AI Resume Analyzer

An AI-based Resume Analyzer that compares a resume with a job description and calculates a matching score.

## Features

- Upload resume in PDF format
- Extract text from resume
- Compare resume with job description
- Calculate ATS matching score
- Identify matching skills
- Identify missing skills
- Provide useful resume improvement suggestions

## Technologies Used

- Python
- Flask
- PyPDF2
- Scikit-learn
- TF-IDF
- Cosine Similarity
- HTML
- CSS
